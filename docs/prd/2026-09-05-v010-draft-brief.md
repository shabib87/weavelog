## CLI surface

| Command | Job |
|---|---|
| `weavelog init` | verify required external-tool prerequisites through pinned instructions, then materialize shared skills and OpenCode-native configuration from declared package inputs; normal conflicts refuse; confirmed `--force` replacement preserves a protected backup; does not install external tools |
| `weavelog sync` | dev path: repo → live (dogfood loop; ported config-sync.ts) |
| `weavelog update` | release-driven dep bump + re-materialize |
| `weavelog check` | deterministic gates: tests, lint, typecheck, semgrep (telemetry off, pinned rulesets), secrets, frontmatter, manifest completeness |
| `weavelog doctor` | installed? authenticated? config parses? proxy healthy? cache mode=cache? python3.13? :8788 launchd-owned? semgrep smoke? ledger tail? |
| `weavelog scaffold --project` | project: initialize Backlog; create project-owned conductor-era `AGENTS.md`, `.env.example`, and neutral docs README homes for research, ADR, PRD, and TRD; do not manage `.gitignore`, `.env`, `.env.local`, or `.git` |

- Manifest: JSON (`weavelog.json`), CLI-managed; per-tool install channel (brew/pipx/npm/uv)
  + version + doctor check id. Completeness rule: every external binary invoked in skills/src/payload
  must appear in manifest (check-enforced).
- Ledger: append-only JSONL at ~/.local/state/weavelog/; every command logs files touched,
  decisions, errors, exit code. Zero silent failure: refusal = log line + non-zero exit.
- Post-flip ~/.agents: shared open-standard skills only. Host behavior rules
  live in each verified host's native configuration root; for OpenCode, that
  is `~/.config/opencode/AGENTS.md`. No git, node_modules, or state under
  `~/.agents`. Sync state → ~/.local/state/weavelog/.
- Host-specific plugin files are CLI-managed artifacts (src/hooks/, emitted per host).
- ~/.agents/docs → weavelog/docs (privacy sweep gates public flip). Personal second-brain
  notes stay local unversioned. Backlog moves to weavelog/backlog now.

## Runbook decomposition rule

Every section gets exactly one fate: script (init/check/doctor/update logic),
architecture doc (docs/trd/<topic>.md), payload template, or delete.
Nothing stays prose-only. Key mappings: fresh-Mac checklist+Phase 0 → init;
Phase 1 health/smoke/ownership/cache-mode → doctor checks + docs/trd/headroom-proxy.md
(cache-mode rationale, pricing-sync why, :8788 single-owner); Phase 2 → payload/opencode.jsonc
template + doctor config-parse; Phase 3 → payload/agents templates; Phase 4 gotchas → init
symlink logic; pricing sync → src/sync-model-pricing.ts + doctor; model tiers → payload
models.json default + docs/trd/model-routing.md (protocol stays, dated table becomes
example); safe-update procedures → update; verification battery → doctor subchecks; prune
rules → backlog tasks with triggers; carry-over manifest → this port; quick reference → README
quickstart + docs/cli.md.

## 2026-09-12 correction — canonical CLI distribution contract

The approved target contract is recorded in [ADR-0008](../adr/0008-cli-distribution-contract.md)
and specified in [the CLI vision](../trd/cli-vision.md). Weavelog is an
opinionated, greenfield-first harness. The package fans shared skills to
`~/.agents` and OpenCode-native configuration to `~/.config/opencode`.
`payload/config/harnesses/opencode.json` is strict JSON control metadata;
`payload/config/opencode.jsonc` is the full human-maintained OpenCode
configuration template.

Normal target conflicts refuse before writes. An explicit `--force` can
replace only an eligible declared leaf file after confirmation. The CLI first
preserves an opaque `.bak` in protected local state and journals the action.
Scaffold creates the four docs homes and does not manage `.gitignore`,
`.env`, `.env.local`, or `.git`. This section records target behavior; TASK-29,
TASK-30, TASK-66, and TASK-67 own implementation and release proof.
