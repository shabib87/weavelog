# DeepSeek V4.1 Flash — Seat-Eligibility Hold and Manual A/B Provisional Entry

**Date:** 2026-09-11
**Status:** open — 4.1-flash held out of seats pending protocol-pinned benchmark scores; manual A/B only
**Supersedes:** none
**Related:** ADR-0004 (model-selection benchmark policy, superseded by ADR-007 for reviewer fallback; benchmark selection and drift governance carried forward), `2026-09-07-flagship-tier-pricing-quality-preliminary.md` (TASK-61 pricing matrix)

## Trigger

DeepSeek released `deepseek/deepseek-v4.1-flash` on OpenRouter on 2026-09-10 —
a new slug in a monitored family (`deepseek`). Per ADR-0004's weekly sweep rule
(new slug in a monitored family triggers the sweep), this note records the
evaluation hold before any seat assignment is considered.

During a config session on 2026-09-11 the model was briefly set as the default
on pi (`defaultModel`) and opencode (`model`) based on incomplete data. That
change was reverted the same day. This note records the correction.

## What exists today (evidence inventory)

| Evidence | Status under ADR-0004 | Detail |
|---|---|---|
| Vendor-reported DeepSWE v1.1: 74.2 (4.1-flash) vs 63.4 (GLM 5.3 Flash) | rejected as primary; requires `unverified` tag + independent corroborator | Each vendor's own run, non-comparable protocol |

| Yotta Labs comparison (2026-09-10) | advisory only | Specs + pricing, no AA instruments |

Verifiable specs from the advisory source: 552B sparse MoE (encoder-decoder),
8B/16B active prefill/decode, 1M context, 384K max output, text+image input,
MIT license. Pricing off-peak $0.15/$0.60, peak $0.30/$1.20, cached input
$0.003/$0.006. Peak pricing (2x) is a cost-profile difference from GLM 5.3
Flash's flat $0.15/$0.50 that any seat decision must account for.

## Decision recorded

1. **No seat assignment.** 4.1-flash is not seat-eligible: zero scores on all
   three primary instruments (TB 2.1, SWE-bench Pro, HLE-with-tools).
2. **Defaults reverted.** pi `defaultModel` and opencode `model` returned to
   `z-ai/glm-5.3-flash` (L0 seat per the ADR-0004 ladder).
3. **Manual A/B provisionally enabled** (human decision, 2026-09-11): the
   model stays in pi `enabledModels` and takes opencode's `small_model` slot,
   giving the human a live comparison slot on both hosts. This is a human
   override per PRODUCT ("init asks and flags override") and confers no
   ladder status.
4. **Escalation path unchanged.** `deepseek-v4-pro-0813` remains L1. V4.1
   Flash does not replace it: flash-tier vs pro-tier, and no SWE-bench Pro
   evidence exists for the flash model.
5. **`deepseek-v4-flash-0731` retained** on the pi roster for cheap bulk work
   (10x cheaper on output than 4.1-flash off-peak). Its retirement is a
   separate human decision after 4.1-flash is scored.

## Data-hygiene corrections recorded (process learning)

The 2026-09-11 session initially made the default swap citing OpenRouter
`/api/v1/models` benchmark fields. Post-hoc check found:

- OpenRouter's benchmark block carried stale AA index values (GLM 5.3 Flash
  intelligence 41.9 vs 57 on the current AA Intelligence Index v4.3) and
  mixed index versions in one table.
- Vendor-run comparisons were presented adjacent to independent indexes
  without a clear `unverified` tag on first pass.

This matches the ADR-0004 "rejected as primary evidence" table exactly: the
failure mode the policy exists to prevent. OpenRouter benchmark fields are
demoted to watch-list signals only; seat decisions cite the governing AA
table directly.

## Re-evaluation trigger

When Artificial Analysis publishes Terminal-Bench 2.1, SWE-bench Pro, and
HLE-with-tools entries for DeepSeek V4.1 Flash under a consistent protocol,
produce the monthly deep-refresh decision brief comparing it against the L0
seat holder (glm-5.3-flash) and the frontier anchors per ADR-0004. The human
then decides roster entry and seat. Until then this note stays `open`.
